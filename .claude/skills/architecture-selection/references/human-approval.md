# 非可逆操作の承認

この文書は、エージェントが実行する前に人間の承認を得る操作を定める。このスキルの中で最も優先するルールで、他の文書の必須や推奨はこれを緩められない。[編集制約](./editing-constraints.md) は、この基準をサービスのリポジトリのパスと操作に当てはめたものである。

## 承認が要る操作

**必須**

次の操作は、実行する前に必ず人間の承認を得る。

| 種類 | 操作 |
| --- | --- |
| 人や外部とのやりとり | メール、チャット、SNS への送信や投稿。GitHub や課題管理ツールなど外部サービスへのコメント |
| サービスの設定 | アカウント、権限、API、Webhook の設定変更。サービスの有効化と無効化 |
| お金 | 購入、課金やサブスクリプションの変更、支払い情報の変更 |
| データの削除と変更 | クラウド上のファイルやデータの削除。本番環境や重要なデータを含むデータベースの変更。リポジトリや重要な設定ファイルの削除 |

## 承認が要らない操作

次の準備作業は、承認なしで行ってよい。

- 下書きの作成(メール、記事、コメントなど)
- ローカルのファイルの編集
- 調査、情報の取得と閲覧
- テスト環境での操作(テスト用のデータベースへの変更を含む)
- 分析とレポートの作成

## 承認の求め方

**必須**

- 何を行うか、どこに影響するか、元に戻せるかを示す。
- 承認を得るまで実行しない。返事がなくても、時間切れで実行に進まない。
- より安全な代わりの手段や、段階的に実行する方法があれば示す。

## 例外

緊急時の自動対応を明示的に設定した場合に限り、承認なしで実行してよい。その場合も、実行した後に必ず報告する。

## 判断に迷ったとき

元に戻せるかどうか迷う操作は、承認が要るものとして扱う。
