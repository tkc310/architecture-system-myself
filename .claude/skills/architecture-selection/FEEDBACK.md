# このスキルへのフィードバック

スキルを使った後、判定や雛形が合わなかった点を記録する。同じ種類が 2 回出たら SKILL.md / references / templates を直す。

| 日付 | 使った案件(概要) | 選んだ構成 | 合わなかった点 | 対応 |
|------|--------------------|------------|----------------|------|
| | | | | |

見直しの観点:
- 判定フローの質問で決めきれなかったケースはないか
- 選んだ構成が後で昇格/降格したか。その条件は ADR に書いた昇格条件と一致したか
- 雛形の設定が現行版のツールで動かなかったか
- LESSONS.md から昇格したルールのうち、他の案件でも使えるものはないか(あれば templates に取り込む)
