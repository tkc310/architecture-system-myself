# 出力の自己点検チェックリスト

出力を渡す前にすべて確認する。満たせない項目は理由をユーザーに伝える。

## 選定
- [ ] 判定フローの各質問への答えと、その根拠(聞き取り結果または既定値)が ADR にある
- [ ] 要件を満たす中で最も単純なアーキタイプを選んでいる
- [ ] L1 なのにドメイン層・リポジトリ層・DI を作っていない
- [ ] 昇格条件(と、該当すれば降格条件)が ADR にある
- [ ] 性能段を上げた場合、計測結果または計測計画が ADR にある
- [ ] P3 以上・Go 採用はユーザー確認済み

## 技術スタック
- [ ] 採用ライブラリの現行版と導入手順を公式ドキュメントで確認した
- [ ] 既定から外した項目はすべて ADR に理由がある

## ディレクトリ構成とハーネス
- [ ] ディレクトリ構成と `.dependency-cruiser.cjs` のパスが一致している
- [ ] 空の雛形で `pnpm check` が通る
- [ ] 意図的に境界違反のファイルを置くと `pnpm lint:deps` が失敗する(確認後に削除)
- [ ] AGENTS.md には機械で強制できないルールだけが書かれている
- [ ] `docs/feedback/LESSONS.md` と昇格の運用ルールがある

## ADR
- [ ] 1 ADR = 1 決定。性能段 P2 以上、Go、既定からの逸脱は別 ADR
- [ ] 検討した代替案と、採用しなかった理由がある
- [ ] 状態(提案/承認/置換)と日付がある
